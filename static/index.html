Most document leaks happen silently. A screenshot hits a forum, an offline laptop stays disconnected, and traditional access control stays blind.

SentinelTrace hides mathematical proof inside every sentence and shreds RAM decryption keys the instant a monotonic lease expires.

How It Works

One source file, then parallel verification gates

Every distribution generates redundant zero-width chunks, PDF vector overlays, HMAC-SHA256 signatures, and monotonic RAM lease checks before attribution confirms.

Partial Snippets Survive

Embedding zero-width sequences (\u200b, \u200c, \u200d) after every sentence lets judges delete paragraphs and still recover Alice’s exact session.

Clock Rewinds Fail

Offline leases bind RS256 signed JWTs to relative monotonic clock deltas (time.monotonic()), catching manual OS clock tampering in milliseconds.

Original PDFs Stay Intact

Copy-to-copy PDF watermarking preserves 100% of original layouts while overlaying transparent ArialUnicode binary text and signed PDF metadata.

Converts recipient_id|session_id|hmac8 into 8-bit binary frames mapped to \u200b (0) and \u200c (1), framed by \u200d. Injected cleanly after every sentence delimiter so partial copy-pastes retain multiple full payloads.
Tracks elapsed uptime with Python time.monotonic() alongside client_elapsed_seconds and RS256 signed JWT lease envelopes. Any negative wall-clock drift triggers immediate tamper flags and key destruction.
Confidential content never lands unencrypted on disk. When /api/revoke-lease or natural lease expiration runs, the active AES-256-GCM key buffer is zeroed out (0x00...RAM-ZERO-FILLED) and the UI curtain locks.
Uses pypdf (PdfWriter(clone_from=...)) and reportlab with ArialUnicode TTF font support to stamp an invisible vector layer + signed /Author and /Subject metadata directly onto original PDFs without altering typography.
